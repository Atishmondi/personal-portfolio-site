## The work

I’m a computer science graduate interested in how technical systems work and how to make their behavior understandable.

Six solo projects, with short films, case studies, and saved records you can explore.

| Project | A look inside |
| :--- | :--- |
| **01** · [Federated Learning](https://atishmondi.github.io/personal-portfolio-site/federated-learning.html) | Training curves across simulated clients with different data distributions. |
| **02** · [Purchase-to-Pay](https://atishmondi.github.io/personal-portfolio-site/p2p-conformance.html) | Purchasing rules, event sequences, and the difference between a violation and an incomplete record. |
| **03** · [Elbow ROM](https://atishmondi.github.io/personal-portfolio-site/elbow-rom.html) | Video-derived elbow angles, rejected frames, and the measurements behind a report. |
| **04** · [Rental Architecture](https://atishmondi.github.io/personal-portfolio-site/rental-architecture.html) | What happens to bookings and invoices when a worker fails—and how recovery behaves. |
| **05** · [Note124](https://atishmondi.github.io/personal-portfolio-site/note124.html) | Capturing text and screenshots in Discord, then finding them again through tags and search. |
| **06** · [Glucometer](https://atishmondi.github.io/personal-portfolio-site/glucometer.html) | A Flask application for XML uploads and short glucose forecasts. |

## The atmosphere

Deep blue scenes, bold type, and angled menus inspired by **Persona 3**. Background motion, scene transitions, and contact reflections carry the theme through the site. Keyboard navigation, a motion toggle, and reduced-motion support keep it usable.

The project pages include their findings and limitations. Interactive evidence reads saved experiments; the portfolio doesn’t run live model training or process new uploads.

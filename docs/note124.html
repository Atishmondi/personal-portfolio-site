KNOWLEDGE TOOLS · AI INTEGRATION

Note124

Capture now. Find it again later.

A Discord knowledge-capture bot that preserves original material and adds structured metadata, retrieval, and digests.

PythonDiscord.pySQLitePydanticGemini API
GitHub profile ↗
THE TAKEAWAY

The original capture remains valuable even when enrichment fails.

The question

Useful text and screenshots accumulate faster than they are organized. Note124 explores a capture-to-rediscovery loop inside Discord without replacing the original material with an AI summary.

The approach

A capture is stored with its original input. One structured Gemini call generates a title, summary, tags, and type. Embeddings support semantic retrieval; SQLite keyword matching provides a fallback. User-scoped queries and scheduled weekly digests complete the loop.

Failure behavior

The design preserves a capture when metadata generation fails and keeps keyword search available when embedding generation fails. Those fallback paths are more meaningful than treating every AI request as a dependency that must always succeed.

Scope and assistance

Solo project. The bot integrates upstream Gemini understanding and embedding models. It is a personal knowledge-tool project, not a newly trained model. The portfolio does not claim production adoption or perfect isolation or hallucination prevention.

Limits and next investigation

Live behavior depends on API availability, credentials, and Discord permissions. There is no public interactive bot here: a portfolio visitor cannot access private captured notes. A current independent public repository for the rebuilt Note124 has not been established, so the link below goes to the author’s GitHub profile.
